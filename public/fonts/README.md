# Fonts

Place licensed **Degular Display Semibold** files here (OH no Type Co.):

- `DegularDisplay-Semibold.woff2` (required)
- `DegularDisplay-Semibold.woff` (optional fallback)

Until these files exist, the site falls back to Archivo for display headlines.

Archivo is loaded via `next/font/google` (weights 400 / 500 / 600).
